# Catálogo Kona Moda

Exportación completa de la tienda konamoda.pe (WooCommerce Store API).

- **84 productos**, **416 imágenes**.
- `productos.csv` — tabla con nombre, SKU, precios (normal/oferta), categorías, tallas, descripción y URLs.
- `catalogo-completo.json` — respaldo crudo de la API (todos los campos).
- `productos/<slug>/` — una carpeta por producto con:
  - `producto.json` — datos del producto.
  - imágenes numeradas por orden (`01-...`, `02-...`).
